# 🔥 Dia 7 — Seu primeiro projeto completo

## 🎯 Objetivo
Juntar todos os conhecimentos dos dias anteriores para construir uma aplicação completa e conectada.

## 💡 Ideia geral
Você vai construir uma pequena aplicação real usando HTML, CSS e JavaScript Vanilla.

Sugerimos um **Painel de Previsão do Tempo** ou **Buscador de Personagens**.
Na aplicação, o usuário deverá poder buscar alguma informação consumindo uma API externa. Caso o usuário goste da informação obtida (ex: o clima da cidade ou um personagem favorito), ele poderá salvá-la em uma lista lateral de "Favoritos". Essa lista deve ser persistida para que continue lá quando ele voltar amanhã.

*(Se quiser escolher outro tema para a aplicação, fique à vontade, contanto que contemple todos os requisitos).*

## 📋 Requisitos obrigatórios
O seu projeto final precisa obrigatoriamente envolver:
- Interface HTML/CSS bem estruturada.
- Manipulação do DOM (exibir dados, criar elementos na tela dinamicamente).
- Uso de Eventos (escutar cliques em botões e envios de formulários).
- Uso de condicionais, funções e lógica para coordenar as ações.
- Listas (Arrays) e Objetos para organizar as informações recebidas ou favoritadas.
- Métodos de array para listar, buscar ou remover favoritos.
- Um campo de formulário com validação básica antes da pesquisa.
- Armazenamento local usando `localStorage` (salvar, ler, renderizar na tela).
- Consumo de uma API externa com `fetch`.
- Uso de assincronismo (`async` / `await`).
- Tratamento visual de erros caso a busca falhe ou a API saia do ar.

## ⭐ Requisitos opcionais
- Tema escuro / claro.
- Animações CSS para o carregamento (loading).
- Um botão em cada item favoritado que permita removê-lo especificamente do array e do localStorage.

## 🧠 O que precisa ser aplicado
É hora de ligar os pontos:
- As funções (Dia 2) criam a lógica.
- Os arrays e objetos (Dia 3) formam a estrutura dos seus dados.
- O DOM e eventos (Dia 4) são os seus botões e inputs funcionando no HTML.
- O formulário e o localStorage (Dia 5) salvam as preferências.
- A API (Dia 6) busca os dados reais na web.

## 🚫 Limitações
- Use **apenas** JavaScript Vanilla. Nada de React, Vue, jQuery.
- Não copie arquiteturas prontas. Use o raciocínio.
- Quebre os problemas em partes pequenas antes de programar!
