# ⚡ 7 Days of Code — JavaScript

Bem-vindo(a) ao **7 Days of Code — JavaScript**! 🚀

Este desafio foi criado para quem quer praticar e dominar os fundamentos do JavaScript, saindo do zero absoluto e chegando a um nível intermediário. 

O objetivo não é apenas ler teoria, mas sim colocar a mão na massa, desenvolver seu raciocínio lógico e criar projetos práticos. 

**Como estudar durante os 7 dias:**
- Faça apenas um dia por vez.
- Separe um tempo sem distrações.
- Leia o objetivo e o material de estudo.
- Tente resolver o desafio prático usando sua própria lógica.
- Comemore cada pequena vitória!

---

> ### 🚫 NÃO USAR IA PARA FAZER O DESAFIO POR VOCÊ.
>
> A inteligência artificial é uma ótima ferramenta, mas ela pode atrapalhar o seu aprendizado se fizer o trabalho pesado por você.
>
> **A IA pode ser usada APENAS depois de você tentar sozinho**, principalmente para:
> - entender um erro;
> - receber uma explicação de um conceito;
> - revisar uma solução que **você já fez**;
> - tirar dúvidas específicas.
> 
> A ideia é desenvolver o **seu** raciocínio e a **sua** autonomia.

---

> ### 🔥 Regra nº 1: COMMITAR NO FIM DE CADA DIA.
>
> No mundo real da programação, versionamento é fundamental. Cada dia deve terminar com um commit no seu repositório Git, para acompanhar a evolução e construir o seu portfólio.

---

## 🗺️ O seu caminho

- 🟢 Dia 1 — Fundamentos do JavaScript
- 🟡 Dia 2 — Condições, funções e lógica
- 🟠 Dia 3 — Arrays, objetos e loops
- 🔵 Dia 4 — DOM e eventos
- 🟣 Dia 5 — Formulários e LocalStorage
- 🔴 Dia 6 — Assincronismo, Fetch e APIs
- 🔥 Dia 7 — Projeto final

---

## 🏆 Regras do desafio

Para extrair o máximo desse projeto, comprometa-se com estas regras:
- Fazer um dia por vez.
- Tentar resolver sozinho antes de buscar respostas.
- Não copiar soluções prontas.
- Pesquisar documentação quando necessário.
- Cometer o projeto ao final de cada dia.
- Só avançar quando conseguir explicar o que fez.
